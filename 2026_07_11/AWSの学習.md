```md
## DevOps・データ分析・機械学習関連用語

| 用語 | 説明 |
|------|------|
| DevOps | 開発と運用が連携し、効率的にシステムを開発・運用する考え方。 |
| CI（Continuous Integration） | コードのビルド・テストを自動化する仕組み。 |
| CD（Continuous Delivery / Deployment） | アプリケーションのデプロイを自動化する仕組み。 |
| CodeCommit | Gitリポジトリを管理するAWSサービス。 |
| CodeBuild | ソースコードのビルド・テストを自動実行するサービス。 |
| CodePipeline | ビルドからデプロイまでを自動化するサービス。 |
| CodeDeploy | アプリケーションを自動デプロイするサービス。 |
| Elastic Beanstalk | アプリケーションを簡単にデプロイ・運用できるサービス。 |
| データアナリティクス | データを分析して有益な情報を得ること。 |
| データソース | データの取得元となるシステムやサービス。 |
| オープンデータソース | 誰でも利用できる公開データ。 |
| データレイク | 様々な形式のデータをそのまま保存する保管場所。 |
| バッチデータ収集 | 一定時間ごとにまとめてデータを収集する方式。 |
| ストリーミングデータ収集 | データをリアルタイムで収集する方式。 |
| ビッグデータアーキテクチャ | 大量データを効率的に処理するシステム構成。 |
| HDFS | Hadoopで使用される分散ファイルシステム。 |
| MapReduce | 大量データを並列処理するプログラミングモデル。 |
| YARN | Hadoopクラスタのリソース管理を行う仕組み。 |
| ストリーム処理 | リアルタイムでデータを処理する方式。 |
| Kafka | リアルタイムデータを高速に配信・処理する基盤。 |
| BI（Business Intelligence） | データを分析し、経営判断に活用する仕組み。 |
| Tableau | データを可視化・分析するBIツール。 |
| Amazon Kinesis | リアルタイムデータを収集・処理するAWSサービス。 |
| AWS Glue | データの抽出・変換・読み込み（ETL）を自動化するAWSサービス。 |
| 機械学習（Machine Learning） | データから学習し、予測や分類を行う技術。 |
| ワークフロー（Workflow） | 一連の処理手順や作業の流れ。 |
| マネージドサービス | AWSが運用・保守を行うクラウドサービス。 |
| Vision | 画像認識・画像解析を行うAI技術。 |
| Speech | 音声認識・音声合成を行うAI技術。 |
```
