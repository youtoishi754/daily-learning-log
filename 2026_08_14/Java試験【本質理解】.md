# setter・getter・this

## setter

### 単語の意味
フィールドに値を設定するためのメソッド。

### 本質理解
オブジェクトのフィールドを外部から安全に変更するために使う。

例：
`setName("田中");`

```text
外部
 ↓
setter
 ↓
フィールド
```

---

## getter

### 単語の意味
フィールドの値を取得するためのメソッド。

### 本質理解
オブジェクトのフィールドを外部から読み取るために使う。

例：
`getName();`

```text
フィールド
 ↓
getter
 ↓
外部
```

---

## this

### 単語の意味
現在のオブジェクト自身を表すキーワード。

### 本質理解
「このオブジェクトのフィールド・メソッド」を明確に指定するために使う。

```text
this.name
 ↓
現在のオブジェクトのname
```

setterでは、引数とフィールドの名前が同じ場合によく使う。

例：
`this.name = name;`

```text
this.name
   ↑
オブジェクトが持つフィールド

name
 ↑
メソッドの引数
```

つまり、

**setter → 値を設定**  
**getter → 値を取得**  
**this → 現在のオブジェクトを指す**

という関係。
