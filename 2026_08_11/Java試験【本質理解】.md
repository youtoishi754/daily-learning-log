
# オブジェクト（Object）

## 単語の意味
データと処理をひとまとめにした、プログラム上の「もの」。

## 本質理解
オブジェクト指向では、現実世界の「もの」をプログラム上のオブジェクトとして表現する。

```
オブジェクト
├─ 属性（データ）
└─ 操作（処理）
```

例：ユーザー

```
ユーザー
├─ 名前
├─ 年齢
└─ ログインする()
```

---

# メソッド（Method）

## 単語の意味
オブジェクトが持つ処理・動作を定義したもの。

## 本質理解
「何をするか」を表す。

```text
User
└─ login()
```

`login()` がメソッド。

---

# 属性（Attribute）

## 単語の意味
オブジェクトが持っているデータや状態。

## 本質理解
「何を持っているか」「現在どんな状態か」を表す。

```text
User
├─ name = "田中"
└─ age = 30
```

`name` や `age` が属性に相当する。

Javaでは、一般的にクラスのフィールドとして表現される。

---

# 操作（Operation）

## 単語の意味
オブジェクトが行う処理・動作。

## 本質理解
「何ができるか」を表す。

```text
User
├─ name
├─ age
└─ login()
```

`login()` のような処理が操作に相当し、Javaではメソッドとして実装される。

---

# 4つの関係

```text
             オブジェクト
                  │
        ┌─────────┴─────────┐
        ↓                   ↓
      属性                 操作
    （データ）             （処理）
        │                   │
      name                login()
      age                 logout()
```

つまり、

**オブジェクト = 属性（データ）＋操作（処理）**

と考えると理解しやすい。
