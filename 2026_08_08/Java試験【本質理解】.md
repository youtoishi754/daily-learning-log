
# while文

## 単語の意味
条件がtrueの間、処理を繰り返す文。

## 本質理解
**条件を先に判定してから処理する**ループ。

条件が最初からfalseなら、処理は1回も実行されない。

```
条件判定
 ↓
true → 処理 → 条件判定へ戻る
 ↓
false
 ↓
終了
```

---

# do-while文

## 単語の意味
処理を実行してから条件を判定する文。

## 本質理解
**処理を最低1回実行してから条件を確認する**ループ。

```
処理
 ↓
条件判定
 ↓
true → 処理へ戻る
 ↓
false
 ↓
終了
```

### while文との違い

```
while
条件 → 処理
最低0回

do-while
処理 → 条件
最低1回
```

---

# 無限ループ

## 単語の意味
終了条件が成立せず、処理が永遠に繰り返される状態。

## 本質理解
ループを終了する条件が存在しない、または条件が永遠にtrueになることで発生する。

```
条件
 ↓
true
 ↓
処理
 ↓
条件
 ↓
true
 ↓
処理
 ↓
∞
```

意図的に使用する場合もあるが、終了条件の設定ミスによって発生することもある。

# for文

## 単語の意味
初期化・条件・更新をまとめて記述できる繰り返し文。

## 本質理解
**「何回繰り返すか」が決まっている処理に向いているループ。**

```text
for (初期化; 条件; 更新) {
    処理
}
```

実行順序：

```
初期化
  ↓
条件判定
  ↓
true → 処理
  ↓
更新
  ↓
条件判定へ戻る
  ↓
false → 終了
```

---

# while・do-while・forの違い

```text
while
→ 条件を先に確認
→ 0回以上

do-while
→ 処理を先に実行
→ 1回以上

for
→ 初期化・条件・更新をまとめて管理
→ 回数が決まった処理に向いている
```
