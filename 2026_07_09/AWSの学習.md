## ストレージ関連用語

| 用語 | 説明 |
|------|------|
| ストレージ（Storage） | データを保存するための記憶領域。 |
| オブジェクトストレージ（Object Storage） | データをオブジェクト単位で保存・管理するストレージ方式。 |
| Amazon S3（Simple Storage Service） | オブジェクトストレージを提供するAWSのサービス。 |
| S3 Glacier | 長期間・低コストでデータを保管するアーカイブストレージサービス。 |
| メタデータ（Metadata） | データの名前や作成日時など、データに関する情報。 |
| 静的Webサイトホスティング | HTML・CSS・JavaScriptなどの静的サイトをS3で公開する機能。 |
| バケットポリシー（Bucket Policy） | S3バケットへのアクセス権限を設定するポリシー。 |
| IAM（Identity and Access Management） | AWSリソースへのアクセス権限を管理するサービス。 |
| Amazon EBS（Elastic Block Store） | EC2に接続して利用するブロックストレージサービス。 |
