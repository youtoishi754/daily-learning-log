
# ラッパークラス（Wrapper Class）

## 単語の意味
基本データ型（int、doubleなど）をオブジェクトとして扱うためのクラス。

## 本質理解
Javaには基本データ型とオブジェクト型がある。

ラッパークラスは、基本データ型をオブジェクトとして扱えるようにしたクラスであり、コレクションやクラスの機能を利用できるようにする。

```
基本データ型      ラッパークラス

int      → Integer
double   → Double
char     → Character
boolean  → Boolean
```

---

# ボクシング（Boxing）

## 単語の意味
基本データ型をラッパークラスへ変換すること。

## 本質理解
基本データ型をオブジェクトへ変換し、オブジェクトとして扱えるようにする。

```
int
 ↓
Integer
```

---

# アンボクシング（Unboxing）

## 単語の意味
ラッパークラスを基本データ型へ戻すこと。

## 本質理解
オブジェクトから基本データ型を取り出し、計算や比較などで利用できるようにする。

```
Integer
   ↓
 int
```
