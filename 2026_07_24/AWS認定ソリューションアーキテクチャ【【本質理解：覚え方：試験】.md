| AWS単語                                    | 名前のヒント                            | 本質              |
| ---------------------------------------- | --------------------------------- | --------------- |
| **EC2 (Elastic Compute Cloud)**          | **Compute**＝計算・コンピュータ             | 仮想サーバー          |
| **S3 (Simple Storage Service)**          | **Storage**＝保存                    | ファイル保管          |
| **EBS (Elastic Block Store)**            | **Block**＝ブロック単位、**Store**＝保存     | EC2用ディスク        |
| **EFS (Elastic File System)**            | **File System**＝ファイルシステム          | 共有ストレージ         |
| **RDS (Relational Database Service)**    | **Database**＝データベース               | MySQLなどを管理      |
| **DynamoDB**                             | **DB**＝データベース                     | NoSQLデータベース     |
| **VPC (Virtual Private Cloud)**          | **Virtual**＝仮想、**Private**＝専用     | 仮想ネットワーク        |
| **Subnet**                               | **Sub**＝小さい、**Net**＝ネットワーク        | VPCを分割した区画      |
| **Internet Gateway**                     | **Gateway**＝入口・出口                 | インターネット接続口      |
| **NAT Gateway**                          | **NAT**＝アドレス変換                    | 内部から外へ通信        |
| **Route Table**                          | **Route**＝道順                      | 通信経路を決める        |
| **Security Group**                       | **Security**＝安全                   | サーバー単位の通信制御     |
| **Network ACL**                          | **Access Control List**＝アクセス制御一覧  | サブネット単位の通信制御    |
| **IAM (Identity and Access Management)** | **Identity**＝本人確認、**Access**＝アクセス | ユーザー・権限管理       |
| **CloudWatch**                           | **Watch**＝監視                      | 監視・メトリクス・アラーム   |
| **CloudTrail**                           | **Trail**＝足跡                      | 操作履歴            |
| **CloudFront**                           | **Front**＝前面                      | CDN・配信の最前線      |
| **Route 53**                             | **Route**＝経路                      | DNS（名前からIPへの案内） |
| **ELB (Elastic Load Balancing)**         | **Load Balancing**＝負荷分散           | アクセスを振り分ける      |
| **Auto Scaling**                         | **Auto**＝自動、**Scaling**＝拡大縮小      | サーバー数を自動調整      |
| **Lambda**                               | （固有名。プログラムを必要時だけ実行するサービス名）        | サーバーレス実行        |
