# extends・UML

## extends

### 単語の意味
クラスを継承するときに使用するJavaのキーワード。

### 本質理解
「このクラスは、あのクラスを継承する」と宣言する。

```text
class Dog extends Animal
        ↓          ↓
      子クラス   親クラス
```

`Dog` は `Animal` のフィールドやメソッドなどを引き継いで利用できる。

```text
Animal
  ↑
  │ extends
  │
Dog
```

## UML（Unified Modeling Language）

### 単語の意味
クラスやオブジェクトなど、システムの構造や関係を図で表現するための標準的な記法。

### 本質理解
**プログラムをコードを書く前に、クラスやその関係を図として整理するための設計図。**

クラス図では、クラスを箱で表現する。

```text
┌──────────────┐
│    Animal    │
├──────────────┤
│ - name       │
├──────────────┤
│ + eat()      │
└──────────────┘
       △
       │ 継承
       │
┌──────────────┐
│     Dog      │
├──────────────┤
│              │
├──────────────┤
│ + bark()     │
└──────────────┘
```

### UMLとJavaの関係

```text
UML
 ↓ 設計
クラス・継承関係を図で整理
 ↓
Java
 ↓ 実装
extendsなどで継承を記述
```

つまり、

**UML = クラスや関係を図で設計するための言語**

**extends = Javaで継承を実装するキーワード**

という関係。
