# オーバーライド（Override）・super

## オーバーライド（Override）

### 単語の意味
子クラスが、親クラス（スーパークラス）から継承したメソッドを再定義すること。

### 本質理解
親クラスの処理をそのまま使うのではなく、**子クラスに合った処理へ上書きする**仕組み。

```text
Animal
└─ eat() → 「食べる」

      ↓ 継承・オーバーライド

Dog
└─ eat() → 「犬が食べる」
```

### ポイント
オーバーライドでは、基本的に**メソッド名・引数（シグネチャ）を同じ**にする。

---

## super

### 単語の意味
親クラス（スーパークラス）を参照するためのキーワード。

### 本質理解
子クラスから、**親クラスのフィールド・メソッド・コンストラクタ**を利用するときに使う。

```text
super.メソッド()
```

→ 親クラスのメソッドを呼び出す。

```text
super()
```

→ 親クラスのコンストラクタを呼び出す。

---

## オーバーライドとsuperの関係

```text
        Animal
        └─ eat()
             ↑
             │ 継承
             │
          Dog
        └─ eat()  ← オーバーライド

Dogから親のeat()を使いたい
        ↓
super.eat()
```

つまり、

**オーバーライド = 親の処理を子クラス用に再定義**

**super = 子クラスから親クラスを参照**

という関係。
