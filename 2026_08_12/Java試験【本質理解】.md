# メンバ（Member）

## 単語の意味
クラスの中に定義されている要素の総称。

## 本質理解
クラスが持っている「データ」や「処理」をまとめてメンバと呼ぶ。

```text
クラス
├─ メンバ変数（フィールド）
└─ メンバメソッド
```

---

# メンバ変数（Member Variable）

## 単語の意味
クラスが持つデータを格納する変数。

## 本質理解
オブジェクトの状態や属性を保持する。

例：
`String name;`
`int age;`

---

# フィールド（Field）

## 単語の意味
クラス内で定義された変数。

## 本質理解
Javaでは、一般的にメンバ変数とほぼ同じ意味で使われる。

```text
クラス
└─ フィールド
   ├─ name
   └─ age
```

※厳密には「フィールド」はクラスに宣言された変数を指し、`static`かどうかに関係なくフィールドと呼ぶ。

---

# メンバメソッド（Member Method）

## 単語の意味
クラスのメンバとして定義されたメソッド。

## 本質理解
オブジェクトが行う処理・操作を定義する。

例：
`login()`
`calculate()`

```text
クラス
├─ フィールド → データ・状態
└─ メソッド   → 処理・操作
```

---

# 4つの関係

```text
クラス
│
└─ メンバ
   │
   ├─ メンバ変数 ≒ フィールド
   │    ↓
   │   データ・状態
   │
   └─ メンバメソッド
        ↓
       処理・操作
```

つまり、

**メンバ = クラスが持つ要素**  
**フィールド（メンバ変数） = データ**  
**メンバメソッド = 処理**

という関係。
