# 繰り返し文（反復文）

## 単語の意味
同じ処理を繰り返し実行するための構文。

## 本質理解
同じコードを何度も書かずに、条件を満たす間だけ処理を繰り返せる。

```
開始
 ↓
条件判定
 ↓
true → 処理実行 → 条件判定へ戻る
false → 終了
```

---

# ループ文

## 単語の意味
繰り返し文の総称。

## 本質理解
while文・do-while文・for文など、処理を繰り返す構文の総称。

```
ループ文
├─ while
├─ do-while
└─ for
```

---

# while文

## 単語の意味
条件がtrueの間、処理を繰り返す構文。

## 本質理解
**最初に条件を判定**し、条件がtrueなら処理を実行する。

一度も条件を満たさなければ、処理は実行されない。

```
条件判定
 │
 ├─ true → 処理 → 条件判定へ戻る
 └─ false → 終了
```

---

# do-while文

## 単語の意味
処理を実行した後に条件を判定する繰り返し構文。

## 本質理解
**最初に1回は必ず処理を実行**し、その後に条件を判定する。

```
処理
 ↓
条件判定
 │
 ├─ true → 処理へ戻る
 └─ false → 終了
```

### while文との違い

```
while
条件 → 処理
（0回以上実行）

do-while
処理 → 条件
（1回以上実行）
```
