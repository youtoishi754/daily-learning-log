## ストレージ・アクセス管理関連用語

| 用語 | 説明 |
|------|------|
| ストレージ（Storage） | データを保存するための記憶領域。 |
| オブジェクトストレージ（Object Storage） | データをオブジェクト単位で保存・管理するストレージ方式。 |
| Amazon S3（Simple Storage Service） | オブジェクトストレージを提供するAWSのサービス。 |
| S3 Glacier | 長期間保存するデータ向けの低コストアーカイブストレージ。 |
| メタデータ（Metadata） | データに関する情報（ファイル名、作成日時など）。 |
| 静的Webサイトホスティング | HTML・CSS・JavaScriptのみで構成されたWebサイトを公開する機能。 |
| バケットポリシー（Bucket Policy） | S3バケットへのアクセス権限を設定するポリシー。 |
| IAM（Identity and Access Management） | AWSリソースへのアクセス権限を管理する仕組み。 |
| Amazon EBS（Elastic Block Store） | EC2に接続して使用するブロックストレージ。 |
| AWS IAM | AWSのユーザー・グループ・ロール・アクセス権限を管理するサービス。 |
