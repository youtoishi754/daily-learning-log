## コマンドライン引数（Command Line Arguments）

### 単語の意味
プログラム実行時にコマンドラインから渡す値。

### 本質理解
プログラムの外部から値を受け取り、実行内容を変更できる仕組み。

```text
java Sample 太郎 20
             │   │
             ▼   ▼
          args[0] args[1]
```

`main(String[] args)` の `args` に格納される。

### コミットメッセージ
```
コマンドライン引数の仕組みを理解
```

### 詳細コミットメッセージ
```
プログラム実行時にコマンドラインから値を渡し、
main(String[] args)で受け取る仕組みを理解した。
```

## String型

### 単語の意味
文字列（複数の文字）を扱うデータ型。

### 本質理解
文字や文章を保存・操作するための型。

```text
String name = "山田";
String message = "Hello World";
```

文字列はダブルクォーテーション（`"`）で囲む。

### コミットメッセージ
```
String型の役割を理解
```

### 詳細コミットメッセージ
```
String型は文字列を扱うデータ型であり、
名前や文章などの文字データを保持するために使用することを理解した。
```
