
# インスタンス変数・インスタンスメソッド・static変数・staticメソッド

## インスタンス変数

### 単語の意味
オブジェクト（インスタンス）ごとに保持される変数。

### 本質理解
**「それぞれのオブジェクトが個別に持つデータ」**。

```text
User A → name = "田中"
User B → name = "佐藤"

それぞれ別の値を持つ
```

---

## インスタンスメソッド

### 単語の意味
インスタンスに属するメソッド。

### 本質理解
**「そのオブジェクトのデータを使って行う処理」**。

```text
user.login()
user.getName()
```

インスタンスごとに異なる状態を利用できる。

---

## static変数

### 単語の意味
クラスに属し、インスタンス間で共有される変数。

### 本質理解
**「全インスタンスで共有するデータ」**。

```text
User
 │
 └─ static count = 100
       ↑
   全インスタンスで共有
```

インスタンスを何個作っても、基本的に共有される。

---

## staticメソッド

### 単語の意味
クラスに属するメソッド。

### 本質理解
**「特定のオブジェクトではなく、クラス単位で使う処理」**。

```text
Math.max(10, 20)
```

インスタンスを作らずに、

```text
クラス名.メソッド名()
```

で呼び出せる。

---

# インスタンスとstaticの違い

```text
インスタンス
│
├─ インスタンス変数
│   → オブジェクトごとに持つ
│
└─ インスタンスメソッド
    → オブジェクトの状態を使う


static
│
├─ static変数
│   → クラスで共有
│
└─ staticメソッド
    → クラス単位で使う
```

### 覚え方

**インスタンス = 個別**

**static = 共有・クラス単位**
