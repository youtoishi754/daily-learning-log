## AWS主要サービス

| 用語 | 説明 |
|------|------|
| IAM（Identity and Access Management） | AWSリソースへのアクセス権限を管理するサービス。 |
| VPC（Virtual Private Cloud） | AWS上に仮想ネットワークを構築するサービス。 |
| EC2（Elastic Compute Cloud） | 仮想サーバーを提供するサービス。 |
| EBS（Elastic Block Store） | EC2で使用するブロックストレージ。 |
| ELB（Elastic Load Balancing） | 複数のサーバーへ通信を分散するロードバランサー。 |
| Auto Scaling | 負荷に応じてEC2インスタンス数を自動で増減する機能。 |
| RDS（Relational Database Service） | リレーショナルデータベースを提供するマネージドサービス。 |
| Aurora | AWSが提供する高性能・高可用性のリレーショナルデータベース。 |
| S3（Simple Storage Service） | オブジェクトストレージを提供するサービス。 |
| S3 Glacier | 長期間保存向けの低コストアーカイブストレージ。 |
