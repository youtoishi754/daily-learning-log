# finalメソッド・finalクラス

## finalメソッド

### 単語の意味
`final`を付けたメソッド。子クラスでオーバーライドできなくなる。

### 本質理解
**「このメソッドの処理は、子クラスで変更させない」**という指定。

```text
親クラス
└─ final eat()
       ↓
子クラス
└─ eat() → オーバーライド不可
```

---

## finalクラス

### 単語の意味
`final`を付けたクラス。ほかのクラスから継承できなくなる。

### 本質理解
**「このクラスを親クラスとして使わせない」**という指定。

```text
final class Animal
        ↓
    継承できない

Dog extends Animal
        ↓
    コンパイルエラー
```

---

# finalメソッドとfinalクラスの違い

```text
finalメソッド
→ メソッドをオーバーライドさせない

finalクラス
→ クラスを継承させない
```

### 覚え方

**final = 「これ以上変更・拡張させない」**

```text
finalメソッド
→ メソッドを固定

finalクラス
→ クラスを固定
```
