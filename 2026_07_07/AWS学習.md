
## Amazon EC2 関連用語

| 用語 | 説明 |
|------|------|
| Amazon EC2（Elastic Compute Cloud） | AWS上で仮想サーバーを作成・運用できるサービス。 |
| インスタンスタイプ（Instance Type） | CPU・メモリ・ストレージなどの性能を定義したEC2の構成。 |
| インスタンスファミリ（Instance Family） | 用途ごとに分類されたインスタンスタイプのグループ（汎用、コンピューティング最適化、メモリ最適化など）。 |
| インスタンスサイズ（Instance Size） | 同じインスタンスファミリ内での性能・リソースの大きさ（small、large、xlargeなど）。 |
| AMI（Amazon Machine Image） | EC2インスタンスを作成するためのOSやソフトウェア設定をまとめたテンプレート。 |
| マネジメントコンソール（Management Console） | ブラウザからAWSリソースを管理できるWeb画面。 |
| AWS CLI（AWS Command Line Interface） | コマンドラインからAWSリソースを操作・管理するツール。 |
| 公開鍵（Public Key） | EC2への安全な認証で使用する公開する鍵。 |
| 秘密鍵（Private Key） | 公開鍵と対になる秘密の鍵。EC2へのログイン時に使用する。 |
| ハードウェア専有オプション | EC2を他ユーザーと物理サーバーを共有せずに利用するオプション。 |
| 専有ハードウェアインスタンス（Dedicated Instance） | 専用の物理サーバー上で動作するEC2インスタンス。 |
| 専有ホスト（Dedicated Host） | 物理サーバー全体を専有し、インスタンス配置を管理できるサービス。 |
| プレースメントグループ（Placement Group） | EC2インスタンスの配置を最適化し、通信性能や可用性を向上させる機能。 |
| Auto Scaling | 負荷に応じてEC2インスタンス数を自動で増減する機能。 |
