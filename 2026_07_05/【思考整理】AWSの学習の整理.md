# AWSとは

## AWSとは何か

AWS（Amazon Web Services）とは、

> **インターネット上に企業のITインフラを構築できるクラウドサービス**

です。

従来は企業が

- サーバー
- ルーター
- スイッチ
- ファイアウォール
- データベースサーバー

などの機器を自社で購入し、サーバールームへ設置・運用していました。

AWSでは、これらを**必要なときに必要な分だけ利用できる**ようになります。

---

# AWS全体のイメージ

```
AWS
│
├── ネットワーク
├── サーバー
├── データベース
├── ストレージ
├── セキュリティ
├── DNS
└── 監視
```

AWSは会社のITインフラ全体をクラウド上に構築できるサービスです。

---

# Amazon VPCとは

AWSの中でも最も重要なサービスが **Amazon VPC（Virtual Private Cloud）** です。

VPCとは

> **自分専用の仮想ネットワーク（社内LAN）**

を構築するサービスです。

```
AWS
└── VPC（会社専用ネットワーク）
```

AWSの中に自社専用のネットワークを作り、その中へサーバーなどを配置します。

---

# VPCの中にシステムを構築する

```
会社（VPC）

├── Webサーバー
├── データベース
├── ファイル保存
├── 社員アカウント
├── ファイアウォール
├── インターネット接続
└── 監視
```

これらをAWSでは各サービスで実現します。

|企業の設備|AWSサービス|
|----------|-----------|
|社内ネットワーク|Amazon VPC|
|サーバー|EC2|
|データベース|RDS|
|ファイル保存|S3|
|社員アカウント管理|IAM|
|ファイアウォール|Security Group・Network ACL|
|通信経路|Route Table|
|インターネット接続|Internet Gateway|
|外部通信|NAT Gateway|
|DNS|Route 53|
|監視|CloudWatch|

---

# Dockerとの違い

Dockerは

> **アプリケーションを動かすためのコンテナ技術**

AWSは

> **システム全体を動かすためのクラウド基盤**

です。

イメージすると

```
AWS
 └── EC2
      └── Docker
            └── Laravel
```

DockerはAWSの上で動作することも多く、両者は競合する技術ではありません。

---

# IoTとの相性

AWSはIoTシステムとの相性が非常に良いです。

例

```
Raspberry Pi
      │
      ▼
インターネット
      │
      ▼
AWS
      │
      ▼
Laravel
      │
      ▼
ブラウザ・スマートフォン
```

この構成により

- 温度監視
- 湿度監視
- LED制御
- モーター制御
- 設備監視

などが可能になります。

---

# 工場監視システムの例

```
工場A
工場B
工場C
工場D
      │
      ▼
      AWS
      │
      ▼
監視システム
```

各工場の設備情報をAWSへ集約することで、

- 遠隔監視
- データ収集
- 異常通知
- リアルタイム表示

などを実現できます。

工場が増えてもAWSへ登録するだけで比較的容易に拡張できます。

---

# AWSを学ぶ目的

AWSを学ぶ目的は

> **企業のITインフラをクラウド上で設計・構築・運用できるようになること**

です。

そのためには

- Linux
- ネットワーク
- データベース
- セキュリティ
- Webアプリケーション
- クラウド

を組み合わせて理解することが重要になります。

---

# まとめ

AWSとは、

**企業のITインフラをクラウド上に構築・運用できるサービス群**です。

その中でも

- Amazon VPC：仮想社内ネットワーク
- EC2：仮想サーバー
- RDS：データベース
- S3：ストレージ
- IAM：認証・権限管理
- CloudWatch：監視

などを組み合わせることで、実際の企業システムと同様の構成をクラウド上で実現できます。

IoTやWebアプリケーションとも相性が良く、近年のシステム開発では非常に重要な技術となっています。
