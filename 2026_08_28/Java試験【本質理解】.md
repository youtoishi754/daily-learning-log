
# @Override・アノテーション

## @Override

### 単語の意味
子クラスで親クラスのメソッドをオーバーライドしていることを示すアノテーション。

### 本質理解
「このメソッドは親クラスのメソッドをオーバーライドするものです」とコンパイラに伝える。

```text
親クラス
└─ eat()

      ↓ 継承

子クラス
└─ @Override
   eat()
```

`@Override`を付けることで、メソッド名や引数などが親クラスのメソッドと正しく一致しているかコンパイラがチェックしてくれる。

```java
@Override
public void eat() {
    System.out.println("犬が食べる");
}
```

---

## アノテーション（Annotation）

### 単語の意味
`@`から始まり、クラスやメソッドなどに情報（メタデータ）を付加する仕組み。

### 本質理解
**プログラムのコードに「これはこういう意味・役割ですよ」という情報を付け加える仕組み。**

```text
@Override
   ↓
「これはオーバーライドです」
```

代表例：

```text
@Override
→ オーバーライドを示す

@Deprecated
→ 非推奨であることを示す

@SuppressWarnings
→ 特定の警告を抑制する
```

---

# @Overrideとアノテーションの関係

```text
アノテーション
      │
      └─ @Override
           ↓
    オーバーライドを明示
           ↓
    コンパイラがチェック
```

つまり、

**アノテーション = コードに意味や情報を付加する仕組み**

**@Override = オーバーライドを表すアノテーション**

と覚える。
