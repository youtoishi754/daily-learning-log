# 子クラス・派生クラス・差分プログラミング

## 子クラス（Subclass）

### 単語の意味
スーパークラスを継承する側のクラス。

### 本質理解
親クラスの機能を引き継ぎ、必要な機能を追加・変更するクラス。

```text
スーパークラス（親）
        ↓ 継承
子クラス
```

---

## 派生クラス（Derived Class）

### 単語の意味
スーパークラスから派生して作られたクラス。

### 本質理解
**子クラスとほぼ同じ意味**で、継承によって元のクラスから新しいクラスを作ることを表す。

```text
Animal
  ↓
Dog（派生クラス）
```

---

## 差分プログラミング

### 単語の意味
既存のクラスとの差分だけを記述して、新しいクラスを作る考え方。

### 本質理解
既存の機能をすべて書き直すのではなく、**共通部分は継承して、追加・変更する部分だけを書く**。

```text
Animal
├─ eat()
├─ sleep()
└─ move()
      ↓ 継承
Dog
├─ eat()      ← 引き継ぐ
├─ sleep()    ← 引き継ぐ
├─ move()     ← 引き継ぐ
└─ bark()     ← 差分として追加
```

つまり、

**継承 → 共通部分を再利用**  
**差分プログラミング → 変更・追加部分だけ記述**

という関係。
